new-3dvr

A minimal, batteries-included starter for your next 3dvr.tech experiment. Clean HTML, Tailwind via CDN, and a small JS hook so you can move fast without getting locked into a framework too early.

Vanilla HTML/JS Tailwind (CDN) MIT Licensed
  1. 1. Unzip and run git init in the folder.
  2. 2. Open index.html in your browser or use a local dev server.
  3. 3. Start editing the markup and js/app.js to build your idea.
