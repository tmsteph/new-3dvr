# new-3dvr

Starter repository for new 3dvr.tech experiments and prototypes.

## What's inside

- `index.html` — Simple landing page wired to Tailwind via CDN.
- `js/app.js` — Placeholder for your custom JavaScript.
- `LICENSE` — MIT License so you can share and remix freely.
- `.gitignore` — Basic Node/Web dev ignores.

## Getting started

1. Unzip this project.
2. Initialize a git repo:

   ```bash
   git init
   git add .
   git commit -m "Initial commit: new-3dvr starter"
   ```

3. Open `index.html` in your browser, or use a simple dev server:

   ```bash
   python -m http.server 8080
   ```

4. Start customizing the layout, styles, and behavior for your next 3dvr project.
